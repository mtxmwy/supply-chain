# 供应链管理系统 (SCM React UI)

基于React + TypeScript + Ant Design构建的现代化供应链管理系统前端应用。

## 🚀 功能特性

- **仪表盘** - 数据统计概览，实时监控业务指标
- **商品管理** - 商品信息维护，分类管理，库存监控
- **供应商管理** - 供应商档案管理，合作关系维护
- **采购管理** - 采购订单管理，采购流程跟踪
- **销售管理** - 销售订单处理，客户关系管理
- **库存管理** - 实时库存监控，预警提醒
- **仓库管理** - 仓储设施管理，库位管理
- **门店管理** - 门店信息管理，营业状态监控
- **财务管理** - 财务数据记录，收支统计

## 🛠️ 技术栈

- **React 18** - 现代化前端框架
- **TypeScript** - 类型安全的JavaScript
- **Ant Design** - 企业级UI设计语言
- **React Router** - 前端路由管理
- **Axios** - HTTP客户端
- **Day.js** - 轻量级日期处理库

## 📦 安装与使用

### 环境要求

- Node.js >= 18.0.0
- npm >= 8.0.0

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd scm-react-ui
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm start
   ```
   
   应用将在 http://localhost:3000 启动

4. **构建生产版本**
   ```bash
   npm run build
   ```

## 🔧 开发指南

### 添加新页面

1. 在 `src/pages/` 目录下创建新的页面组件
2. 在 `App.tsx` 中添加路由配置
3. 在 `Layout.tsx` 中添加菜单项

### 自定义样式

- 全局样式修改 `src/App.css`
- 组件样式使用CSS模块或styled-components
- 主题定制可通过Ant Design的ConfigProvider

### API集成

项目已集成axios，可在需要时：
1. 创建API服务模块
2. 配置请求拦截器
3. 处理响应数据和错误
